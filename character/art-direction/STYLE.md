# Mittes 服饰设定图画风 · v1

基准是用户在 2026-10-12 认可的黑白女仆装第二版。文字约束、固定参考图、可复用提示词模板与完整生成记录一起使用，减少后续画风漂移。

## 固定参考

- [外搭基准](reference-outer.png)：来自 `../design-sheets/2026-10-12/maid-split-v2/01_黑白女仆装_外装.png`。
- [内搭基准](reference-inner.png)：来自同目录的 `02_黑白女仆装_内搭.png`。
- `references.json` 记录 SHA-256、来源和用途；生成提示词前自动校验，不能静默改动。

参考图片只控制画风与排版，不把女仆装的领型、蕾丝、颜色或花枝复制到每套服装。新款式以现行衣柜文字为准。需要另外参考款式时，明确标为第二张“款式参考”，画风仍由固定基准控制。

## 画面语言

1. 暖棕色细线，干净但带手绘感，线条轻；不使用粗黑漫画描边或工业制图线。
2. 以衣柜指定配色作平涂；每个褶面最多一至两层柔和赛璐璐阴影。用大而简洁的色块交代褶皱，不堆写实明暗。
3. 奶白、粉灰等浅色保持轻盈；深色服装保留清楚的轮廓，不画成高反差黑块。金属与皮面只留少量高光。
4. 背景近白、干净，无纸张颗粒、摄影棚渐变、织物微距和环境场景。
5. 深暖棕手写中文标题、小面积粉色或款式呼应色下划线、少量配色圆点；标注简短，不把整段文字塞进图里。
6. 服饰是空的平铺单品，主要正面较大、背面较小。外搭附鞋袜与实际配饰；内搭分上装与内裤正反面。所有单品完整入画，留白充足。
7. 可爱感来自比例、柔和配色和精致细节。不要加儿童卡通印花、夸张蝴蝶结或未描述的装饰。每款保留其独立剪裁。

## 内容边界

仅画服饰，不出现人物、脸、头发、皮肤、人体轮廓或人台。外搭图不混入内衣；内搭图不混入外衣、鞋袜或安全裤。花纹和面料必须符合文字描述，不擅自增加透视、镂空或装饰配件。发带、发箍可以作为独立道具画出，头发本身不画。

## 实际生成步骤

1. 读取现行衣柜，运行脚本生成任务；例如：

   `python3 character/art-direction/build_prompts.py --part outer --exclude 黑白女仆装 --out character/design-sheets/新版本/prompts.json`

2. 查看对应固定参考图，把 JSON 中的 `references` 作为 imagegen 的图片参考传入，`prompt` 原样传入。一款一张，外搭与内搭分开。
3. 检查款式与文字、正反面是否一致；检查是否有粗线、写实纹理、阴影过重、衣物裁切、人物或多余单品。
4. 不合格时围绕一个问题修正，仍使用固定基准；不要连续拿上一张变体作唯一参考，以免逐次漂移。
5. 将最终 PNG、完整提示词、生成来源与衣柜快照保存到版本目录，更新图片映射。

用户今后明确更换画风时，另立新版本并记录认可依据；保留 v1，不自动覆盖基准。
