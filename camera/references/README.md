09—14 每次最多一张；没有匹配空间，或只拍食物、独立物品而不拍所在环境时，scene_context=none，仅使用 01。人物照片以 02 为主画风，可按请求最多加一张 15—17，不加载六张景物补充。

所有补充图均由 01 生成，用户已于 2026-10-18 认可并要求接入。补充图只控制同一画风对空间、材质与光影的表现，不复制晴天、暗隧道、台灯、房间布置、器皿、床单、机位或取景。实际内容和光照服从用户请求与日程快照。

先确定自然拍摄动作，再决定人物是否入镜。普通景物可双手持机、手留在镜头后，只有持物展示等实际动作需要时才让手入镜。参考图自身是否有人物不决定成品需要有人物。

衣柜款式图按 character/outfit_images.toml 与当前日程另外加载，只控制款式。上一张照片只维持连续拍摄对象，不覆盖本次画风。主参考、补充参考、外貌和衣柜参考在相机任务里分别记录，并冻结文件及 SHA-256。

15—17 仅提供同一人物画风下的衣料画法与自然局部分享表现，不替代当时穿搭，不复制黑白女仆装、藏青袜子、棕色鞋或固定姿势。真正款式与颜色由当前衣柜图和快照决定。前方角度可用镜自拍，本人拍摄不等于统一俯拍，也不统一成前方拍。
