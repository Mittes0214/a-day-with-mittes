判定依据是画面实际是否有人物。穿在脚上的鞋属于人物局部；脱下单独摆放的鞋、桌上的衣服或包是独立物品。纯物品也可能按需加载衣柜款式图，不因此改用人物画风。

请求看人脸、头发、发型或扎发仍按个人隐私拒绝；拍其他具体人物仍按他人隐私拒绝，均在选择参考和生图之前处理。生活照片不露脸。
