先按用户想看的主体和自然拍摄动作确定构图，再选择画风。普通景物可以双手持机、手留在镜头后；只有持物展示等实际动作需要时才让手入镜，不为分享感、证明拍摄者身份或选择某种画风而额外加手。

画风参考图本身不需要含有手或人物。参考只控制画法，不控制其中的物件、姿势、服饰、取景、光照或是否有人物。

衣柜款式图从 character/outfit_images.toml 按当前日程额外选择，不存放在本目录；拍独立摆放的鞋或衣物时也可以加载，不因此改用人物画风。上一张照片只维持连续拍摄对象，不覆盖本次画风。

拍人脸、头发、发型或扎发，以及拍其他具体人物的请求，继续在选择参考和生图前拒绝。成图不露脸。
