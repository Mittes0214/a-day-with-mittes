# v4 画风跨场景测试

使用用户已认可的 v4 袖口与马尾图作为画风基准；每张独立直接参考 v4，不用其他新图逐张传递画风。

1. 红茶无花果慕斯：按照用户指定原图保留内容与构图，转换到 v4 画法。
2. 吧台拿铁：假想刚做好的咖啡，拉花略偏，近拍杯口。
3. 雨后银杏叶：假想阵雨后的人行道局部，银杏叶、少量积水与透明伞尖。
4. 出门的斜挎包：假想回应用户看包的请求，从自身上方向胯侧拍包、袖口与发尾局部。

后三项是为比较画风而设想的场景，不代表真实日程、天气或已发生事件。衣物款式文字参考现行衣柜，发型按用户新偏好为双马尾。

本轮图片均由内置 image_gen 生成，非 CPA 线上拍照工具测试。未替换生产相机固定参考，也未覆盖用户指定的蛋糕原图。候选尚待用户评估。
